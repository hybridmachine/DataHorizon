Charts export verification
==========================
Date: November 15, 2026. Branch claude/charts-export, based on commit f6c8a6b (the round-trip tests and these
documents are added on top). Machine: the reference Mac (macOS, Darwin 25.6.0), system Python 3.14.6
(Homebrew). Neither openpyxl nor odfpy is installed.

1. Round-trip module
--------------------
Command (repository root):
  PYTHONPATH=service python3 -m unittest discover -s tests -p 'test_chart_round_trip.py' -v
Result: Ran 7 tests in about 3 s, OK, 0 skipped.
  ChartRoundTripTests.test_every_supported_chart_round_trips
    ten charts on two sheets (column, bar, area clustered and stacked; line; pie; scatter; a chart whose sources are on
    another sheet), with titles, axis titles, value axis min and max, all three legend positions, anchors, offsets, sizes
    and drawing order; every series named by a cell reference. XLSX and ODS, inline export with inline import preview,
    and streamed export job with staged import. Charts, cells and import report all equal; the import report holds no
    chart or drawing entry.
  ChartRoundTripTests.test_a_stacked_chart_survives_every_route
    stacked column and bar charts, both formats and routes; no `gap width` entry on import.
  ChartRoundTripTests.test_ods_names_a_text_series_series_n
    the ODS export reports chart.converted / series_name and the series comes back "Series 1"; XLSX keeps the text.
  FixtureRoundTripTests.test_fixture_file_round_trips
    tests/fixtures/charts-two-sheets.xlsx and charts-one-sheet.xlsx: import, export, import (and a third generation),
    both formats, both routes. ODS compares everything but series named by text.
  DocumentedDifferenceTests (three tests): text over 255 characters (axis titles and an XLSX series name) comes back
    at 255; two charts named "Sales" on one sheet come back "Sales" and a unique name; an empty series name comes back
    "Series 1".
No round-trip failure occurred; no product code was changed in this task.
