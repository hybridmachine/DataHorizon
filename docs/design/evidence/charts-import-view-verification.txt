2. Sample-file check through the real service
---------------------------------------------
What this is and is not. The application window could not be driven in this run, so the
owner's sample file was imported through the real service with the SDK (the calls the
desktop's import dialog makes: a staged whole-workbook import for "All sheets", a bounded
selection preview then a one-sheet edit for "One sheet"). The desktop overlays and the
import dialog were therefore NOT exercised on this file (see section 4).

Sample: "Column Chart_Complete.xlsx" (29,584 bytes, owner-supplied, untrusted). Two
worksheets, "Column Chart" and "Stacked Column", each with one column chart. It was copied
into a scratch directory outside the repository, read from there, and is not committed.
Script and outputs live in the session scratchpad, not in the repository:
  script  .../scratchpad/sample-check-script/check.py
  output  .../scratchpad/sample-check/run.txt
  files   .../scratchpad/sample-check/out/   (throwaway workbooks and SVGs)
Command (from the repository root, isolated interpreter, file name passed as an argument):
  python3 -I <scratchpad>/sample-check-script/check.py "<scratchpad>/sample-check/in/Column Chart_Complete.xlsx" <scratchpad>/sample-check/out
It starts a LocalService, then:
  (a) prepare_spreadsheet_file (mode mixed) and import_staged into a fresh workbook;
  (b) for sheet_index 1 and for sheet_index 2: a selection-scope preview at row 1, column 1
      (POST /v1/import/xlsx/jobs), then import_prepared into Sheet1 of its own fresh
      workbook (one workbook per sheet index).
For every workbook it lists the catalog, runs a resolve job and a render job through
resolve_chart and render_chart, and saves the SVG.

Whole workbook (the full report holds 18 entries; totals approximated 9, converted 13,
omitted 89, unevaluable 0, almost all from other features of the file):
  sheet.feature  omitted    drawings                 count 2  samples: Column Chart, Stacked Column
  workbook.feature omitted  charts                   count 2
  chart.converted converted styling: colours         count 2  samples: Chart 1 on Column Chart, Chart 1 on Stacked Column
  chart.converted converted styling: data labels     count 2  (same samples)
  chart.converted converted styling: gap width       count 2  (same samples)
  chart.converted converted styling: gridlines       count 2  (same samples)
  chart.converted converted styling: fonts           count 2  (same samples)
  chart.converted converted size_approximate         count 2  (same samples)
  chart.converted converted legend_position          count 1  sample: Chart 1 on Stacked Column
There are no chart.skipped entries.
One sheet, sheet_index 1 (the preview report): workbook.feature omitted charts (count 2, the
whole file's charts); sheet.feature omitted drawings (count 1, Column Chart); chart.converted
styling: colours, data labels, gap width, gridlines, fonts, and size_approximate, each count 1
on Column Chart.
One sheet, sheet_index 2: workbook.feature omitted charts (count 2); sheet.feature omitted
drawings (count 1, Stacked Column); chart.converted styling: colours, data labels, gap width,
gridlines, fonts, legend_position and size_approximate, each count 1 on Stacked Column.

How noisy: seven chart.converted entries for the two charts (five styling entries, one
size_approximate, one legend_position), none skipped. Each entry names its charts, so a
reader can tell what was dropped. The existing workbook.feature charts and sheet.feature
drawings omitted entries ARE STILL REPORTED for this file even though both charts
imported, so the report both says the charts were omitted and lists them as converted. This
is the known inconsistency noted in compatibility-v0.md, awaiting an owner decision. Also
seen: a one-sheet preview reports workbook.feature charts with the whole file's count (2),
not the selected sheet's.
size_approximate is reported for both charts because each worksheet declares a custom width
for column A (customWidth) and a default row height of 14.4, so the pixel size comes from
default cell sizes (64x20 px) and may differ from the size Excel shows.
