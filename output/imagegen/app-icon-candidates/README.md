# DataHorizon application icon candidates

Created November 3, 2026 using the built-in image generation tool.
These are exploratory PNG candidates with transparent exteriors. The user
preferred Linked Tables and selected its later **3B, Shared Cell**, variation
as the application icon. See `../linked-table-variations/README.md` and
`desktop/icons/README.md` for the selected artwork and deployment assets.

packaging and final edge cleanup remain part of preparing the selected design.

## Exact generation prompts

### Horizon Grid

```text
Use case: logo-brand.
Asset type: one standalone desktop application icon candidate for DataHorizon, a native cross-platform spreadsheet application with reliable SQLite storage and Python programmability.
Style: polished geometric app icon, crisp vector-like edges in a raster PNG, restrained depth, bold high-contrast shapes, balanced negative space, trustworthy and contemporary. Choose a tasteful exploratory color palette; there is no established brand palette.
Composition: square 1024 by 1024 canvas, one centered rounded-square icon tile occupying about 86% of the canvas, genuine transparent exterior outside the tile, large central emblem with generous internal spacing. Front-on orthographic view. Silhouette and main symbol must remain recognizable at 32 pixels.
Constraints: exactly one icon, no presentation board, no interface screenshot, no text, no letters except the explicitly requested abstract monogram if any, no digits, no labels, no watermark, no tiny cells, no hairline details, no sparkles, no decorative background, no external cast shadow. Deliver the isolated icon itself.
Primary request: Create the HORIZON GRID concept. A distinctive, very simple emblem combines a spreadsheet with a rising horizon. In the lower part of the tile, use a compact two-row by three-column grid of six large separated rectangular cells. Above it, a single broad rising semicircle meets a strong horizontal horizon edge aligned with the top of the grid. Make the grid and semicircle feel like one coherent brand mark. Spreadsheet-first, optimistic, clear; avoid a landscape illustration or sunset scenery. Use strong cool/warm contrast if appropriate. No monogram.
```
