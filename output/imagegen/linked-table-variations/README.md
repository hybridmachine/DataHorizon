# Linked-table icon variations

Created November 3, 2026 using the built-in image generation tool.

These three new DataHorizon icon candidates explore the user's preferred
[Linked Tables concept](../app-icon-candidates/03-linked-tables.png), preserving
its blue rounded tile, bold white table shapes, and green connection accent.
All are PNG concept assets with transparent exteriors. The original candidate
is preserved. The user selected **3B, Shared Cell**, as the application icon;
its source and deployment assets are in `desktop/icons/`.

| Variation | File | Direction |
| --- | --- | --- |
| 3A. Balanced Bridge | [3a-balanced-bridge.png](3a-balanced-bridge.png) | Equal tables joined by a short central bridge |
| 3B. Shared Cell | [3b-shared-cell.png](3b-shared-cell.png) | Offset tables share a green cell |
| 3C. Table H | [3c-table-h.png](3c-table-h.png) | Table columns form a minimal H |

The selected artwork is preserved in `desktop/icons/source.png`; native icon
packaging derives from that source by resizing and encoding. The other variants
remain exploratory candidates.

## Reference image

Each generation used `../app-icon-candidates/03-linked-tables.png` as its sole
style and concept reference.

```text
Constraints: exactly one icon, no comparison board, no text, no labels, no numbers, no watermark, no screenshots, no landscape, no database cylinder, no arrows, no dots or decorative extras. Keep the blue/white/green palette of the reference. Deliver the isolated icon itself.
Primary request: Explore a BALANCED BRIDGE. Two separate equal-sized upright white rounded table frames stand side by side, aligned at the same height. Each table has exactly four large deep-blue cell openings arranged as two columns and two rows. A short bold emerald horizontal bridge spans the clearly visible blue gap between the two table frames at mid-height, joining their facing edges. The bridge should not cover the cell openings. Keep the two table silhouettes visibly distinct and the whole composition calm and symmetrical. This is the direct, refined, balanced cousin of the reference.
```
